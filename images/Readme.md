# ☁️ Desafio DIO - Gerenciamento de Instâncias EC2

## 📚 Sobre o Projeto

Este projeto foi desenvolvido durante o laboratório da DIO com foco no gerenciamento de instâncias EC2 na AWS.

O objetivo deste desafio foi compreender os conceitos básicos de computação em nuvem, gerenciamento de instâncias e serviços da AWS na prática.

---

# 🚀 O que aprendi

Durante o laboratório aprendi sobre:

- Amazon EC2
- Amazon EBS
- Amazon S3
- Security Groups
- Gerenciamento de instâncias
- Armazenamento em nuvem
- Acesso remoto via SSH

---

# 💻 Amazon EC2

O Amazon EC2 (Elastic Compute Cloud) permite criar servidores virtuais na nuvem.

Com ele é possível:

- Criar máquinas virtuais
- Gerenciar instâncias
- Configurar segurança
- Escalar aplicações
- Hospedar serviços online

---

# 💾 Amazon EBS

O Amazon EBS é utilizado para armazenamento persistente das instâncias EC2.

Durante o laboratório foi possível aprender:

- Como aumentar volumes
- Persistência de dados
- Criação de snapshots
- Armazenamento conectado às instâncias

---

# 📦 Amazon S3

O Amazon S3 é um serviço de armazenamento de objetos da AWS.

Recursos estudados:

- Upload de arquivos
- Armazenamento em nuvem
- Organização de arquivos
- Gerenciamento de buckets

---

# 🔐 Security Groups

Os Security Groups funcionam como firewall virtual da AWS.

Foi possível aprender:

- Controle de portas
- Regras de entrada e saída
- Segurança das instâncias
- Permissões de acesso SSH
